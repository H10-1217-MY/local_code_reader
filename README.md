# Local Code Reader v1.2

ソースコードを外部のLLMサービスへ送らず、ローカルのOllamaで「このファイルは何をしているか」を説明し、そのまま追加質問できるローカルコード読解ツールです。

## v1.2でできること

- 1ファイルをブラウザから読み込み
- Pythonは `ast` で関数・メソッド・クラス・import・呼び出し先を静的解析
- Pythonの関数・クラスは開始行〜終了行を表示
- その他の言語は軽量なパターン解析
- 静的解析結果 + ソースコードをローカルOllamaへ渡して意味解析
- **静的解析で確認できた事実** と **LLMによる解釈** を画面上で分離
- 解析したファイルについて、そのまま追加質問
- 追加質問では同じソースを再度localhostへ送り、コードを根拠に回答
- 直近の会話を最大8メッセージまで質問コンテキストとして利用
- Q&A内容も「JSON保存」を押した場合だけ解析JSONへ含める
- ソースコードや会話をアプリ側のディスクへ保存しない
- Conda環境が有効でも `run.sh` は必ずプロジェクト内 `.venv` のPythonを使用

## 追加質問の例

- `analyze()` は具体的に何をしていますか？
- このファイルの処理の入口はどこですか？
- 変更したときに影響が大きそうな箇所はどこですか？
- この設定値は何に使われていますか？
- 初めて読む人はどの関数から読むべきですか？

回答では、コードから確認できる場合は関数名・クラス名・行番号を示すようOllamaへ指示しています。この1ファイルだけでは判断できない内容は、その旨を回答させます。

## 対応拡張子

Python / C / C++ / JavaScript / TypeScript / Java / C# / Go / Rust / JSON / YAML / TOML / INI / Shell / PowerShell / SQL / Markdown / Text など。

Python以外の静的解析はv1.2でも簡易版です。LLM側の意味解析と組み合わせて使います。

## 前提

- Python 3.11+ 推奨
- Ollamaがローカルで起動していること
- 使用するモデルが `ollama list` に存在すること

Ollamaが既に起動しているかは次で確認できます。

```bash
curl http://127.0.0.1:11434/api/tags
```

モデル例:

```bash
ollama list
```

必要なら:

```bash
ollama pull qwen3:8b
```

より丁寧なコード説明を優先する場合は、GPU/RAMに余裕があれば `qwen3:14b` などへ変更できます。

## セットアップ

```bash
cd local_code_reader_v1_2
./setup.sh
```

`setup.sh` は `.venv` を作り、依存関係をそこへインストールします。Condaの `(base)` が表示されていても問題ありません。

アプリ起動:

```bash
./run.sh
```

ブラウザで次を開きます。

```text
http://127.0.0.1:8000
```

## v1.1から更新する場合

依存パッケージは増えていないので、既存の `.venv` をそのまま使えます。新しいフォルダへ展開して試す場合は、通常どおり `./setup.sh` を実行してください。

## Q&Aのデータの流れ

```text
ブラウザで解析済みファイルを保持
        ↓
質問を入力
        ↓
ブラウザが元ファイルをBase64化
        ↓
FastAPI /api/ask へ localhost 内で再送
        ↓
サーバー上で復元 + 静的解析
        ↓
Ollama /api/chat
        ↓
回答だけをブラウザへ返却
```

Q&Aのためにサーバー側セッションへソースを保持しません。質問のたびにブラウザが元ファイルを再送します。

## 情報の扱い

このアプリ自身にはソースコードや会話をディスク保存する処理を入れていません。解析時は生のHTTP本文、Q&A時はJSON内のBase64としてlocalhostへ送信し、メモリ上で処理します。

ただし、OS、ブラウザ、プロキシ、シェル履歴、Ollama自体の設定、Webサーバーのログ設定など、別レイヤーまで含めて「絶対に痕跡が残らない」ことを保証するものではありません。機密コードで使う場合は `127.0.0.1` のまま運用し、外部公開しないでください。

## JSON保存

解析後に「JSON保存」を押すと、静的解析・LLM解析に加えて、その時点までのQ&Aも `qa_history` として保存されます。

ソースコード本体はJSONへ含めません。
