LOCAL / OLLAMA

Local Code Reader

プロジェクト全体をgrounding付きで読み、質問に答え、README / ARCHITECTURE / HANDOVER に加え、既存プロジェクトからOS別の環境構築手順を作る v3.5。Environment Setup ModeはOllamaを呼ばず静的解析だけで動きます。

Ollama確認中…
フォルダ未選択

.git / .venv / node_modules / build / dist / __pycache__、空ファイル、生成物などを自動整理します。依存定義・lock・ignore系は原則LLMを使わず構造だけ保持します。v3.5は要約対象ファイル数に上限があります。

フォルダ未選択

v3.5ではコマンドを自動実行しません。依存定義ファイルを最優先し、importだけで見つかったライブラリは候補として分離します。GPUドライバ/CUDA/ROCmは自動確定しません。

ソースコードはアプリ側のディスクへ保存しません。通信先は localhost のFastAPIとOllamaです。
